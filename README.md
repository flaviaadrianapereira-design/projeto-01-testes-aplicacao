## Projeto 01 - Testes de Aplicação

## Objetivo

Realizar testes funcionais em uma aplicação web, executando cenários positivos e negativos, identificando comportamentos inesperados e documentando os resultados dos testes.

O projeto foi desenvolvido como parte da minha formação prática em QA e Testes de Software.

## Escopo

Foram realizados testes envolvendo:

- Cadastro e validação de campos
- Login e validação de credenciais
- Checkbox
- Dropdown
- Upload de arquivos
- Drag and Drop
- Alertas JavaScript
- Entrada de dados numéricos
- Teclas do teclado
- Hovers
- Status Codes HTTP
- Redirecionamento
- Carregamento dinâmico
- Menu flutuante
- Menu de contexto
- Geolocation
- Exit Intent
- Estruturas DOM
- Identificação e registro de comportamentos inesperados

## Tipos de teste

- Testes funcionais
- Testes positivos
- Testes negativos
- Validação de comportamento
- Identificação de possíveis bugs
- Registro de resultados

## Ferramentas e tecnologias

- Visual Studio Code
- Markdown
- Git
- GitHub
- Navegador Web
- The Internet (aplicação utilizada para prática de testes)
