## BUG-002 - Campo não é habilitado após clicar em Habilitar

Título: Campo permanece desabilitado após solicitação de habilitação

Descrição: Ao utilizar a funcionalidade Dynamic Controls, o campo que deveria ser habilitado permaneceu desabilitado durante o teste.

Passos para reproduzir:
1. Acessar a página Dynamic Controls.
2. Localizar o campo desabilitado.
3. Clicar no botão “Habilitar”.
4. Aguardar o carregamento.

Resultado esperado: O campo deve ficar habilitado para receber informações.

Resultado atual: A página permaneceu em estado de carregamento e o campo não foi habilitado.

Severidade: Média

Prioridade: Média

Status: Encontrado
